# איפה זה? 🌍

משחק טריוויה גיאוגרפי מרובה משתתפים בזמן אמת, בעברית. כל סיבוב מציג תמונה של עיר, מונומנט, אתר או מקום מפורסם, וכל שחקן מסמן על מפת עולם איפה לדעתו הוא נמצא. הניקוד נקבע לפי המרחק מהמקום האמיתי.

**תשתית:** TypeScript · `client/server/shared` · Socket.IO (WebSocket) · React + Vite · Leaflet + OpenStreetMap · Docker · Render.

## איך משחקים

1. המארח נכנס ל"יצירת חדר חדש", ובוחר:
   - **קטגוריה:** ישראל, אירופה, אסיה, אמריקה, אפריקה ואוקיאניה, או מעורב (ברירת מחדל).
   - **דרגת קושי:** קל (ברירת מחדל), בינוני או מקצוענים. הדרגה משפיעה רק על בחירת המקומות, לא על הניקוד.
   - **מספר סיבובים:** 5, 10 (ברירת מחדל), 15 או 20. מקום לא חוזר פעמיים באותו משחק. אם אין מספיק מקומות בשילוב שנבחר, המשחק משתמש בכמה שיש ומציג הודעה.
2. השחקנים מצטרפים עם קוד החדר (או סריקת QR) ושם.
3. בכל סיבוב מוצגת תמונה בלי שם. כל שחקן מסמן נקודה על המפה (זום וגרירה חופשיים) ולוחץ **אישור**. יש טיימר לכל סיבוב.
4. אחרי כל סיבוב מוצגים המיקום האמיתי, הניחושים של כל השחקנים והמרחק של כל אחד בק"מ, יחד עם שם המקום, העיר, המדינה ושורת מידע.
5. בסוף המשחק מוצגת טבלת הניצחון.

### ניקוד
`ניקוד = 1000 · e^(−max(0, מרחק − רדיוס בול) / קבוע דעיכה)`

| סקאלה | בול פגיעה | קבוע דעיכה | דוגמאות |
|---|---|---|---|
| עולמית (כל הקטגוריות חוץ מישראל) | 10 ק"מ | 1,000 ק"מ | 100 ק"מ → 914 · 500 ק"מ → 613 · 2,000 ק"מ → 137 |
| ישראל | 1 ק"מ | 25 ק"מ | 5 ק"מ → 852 · 25 ק"מ → 383 · 50 ק"מ → 141 |

## מאגר המקומות

מקור האמת: [`data/places.json`](data/places.json). לכל מקום נשמרים שם, עיר, מדינה, קטגוריה, דרגה, קואורדינטות (WGS84), קובץ תמונה ב-Wikimedia Commons, קרדיט (צלם + רישיון), ושורת מידע. פריטים שיש בהם ספק מסומנים בשדה `note`, כדי שאפשר יהיה לאמת אותם ידנית.

- **תמונות:** רק מ-Wikimedia Commons, ברישיון חופשי (Public domain, CC0, CC BY, CC BY-SA). הכתובת נבנית דרך `Special:FilePath` עם רוחב מתאים. מתחת לכל תמונה מוצג קרדיט עם קישור לדף הקובץ.
- **אימות מבני:** `npm run validate:places`
- **בדיקת תמונות:** `npm run check:images`. הסקריפט עובר על כל המאגר, מוודא שכל תמונה נטענת ושהרישיון שלה חופשי, ומדווח על קישורים שבורים. הבדיקה רצה אוטומטית ב-GitHub Actions בכל דחיפה (`.github/workflows/ci.yml`).
- **בניית מקומות מזרעים:** `node scripts/resolve-places.mjs`. הסקריפט מקבל רשימת זרעים (`scripts/seeds/*.json`), שולף קואורדינטות מ-Wikidata ומוויקיפדיה (ומסמן פער ביניהן), ובוחר תמונה ברישיון חופשי עם הקרדיט שלה.
- **גיליונות סקירה:** `python3 scripts/contact_sheets.py`. הסקריפט מכין לוחות של כל התמונות, כדי לוודא בעין שאין בהן שלט או כיתוב שחושף את התשובה.

## מסך ניהול — `/admin`

מוגן בסיסמה שמוגדרת במשתנה הסביבה `ADMIN_PASSWORD`. בלי הסיסמה המסך כבוי.

1. נכנסים עם הסיסמה. המאגר הנוכחי נטען לטיוטה בדפדפן (`localStorage`).
2. מוסיפים או עורכים מקום: שם, עיר, מדינה, קטגוריה, דרגה, שם קובץ ב-Commons (או קישור לדף הקובץ), קרדיט ושורת מידע. אפשר לשלוף את הקרדיט אוטומטית מ-Commons.
3. **הקואורדינטות נבחרות בלחיצה על המפה בלבד**, בלי הקלדה. תצוגה מקדימה בודקת שהתמונה באמת נטענת, ומקום עם תמונה שבורה לא נשמר.
4. לוחצים **ייצוא**. יורד קובץ `places.json` מלא ומעודכן, ומחליפים בו את `data/places.json` ב-GitHub. Render יפרוס מחדש אוטומטית.

השרת לא כותב לדיסק, כי ב-Render Free ה-filesystem אינו קבוע. מקור האמת הוא תמיד הקובץ ב-repo.

## פיתוח מקומי

```bash
npm install
npm run dev          # שרת על 3000 + Vite על 5173
npm test             # בדיקות יחידה
npm run typecheck
```

## פריסה ב-Render

הקובץ `render.yaml` מגדיר שירות web יחיד (Docker, תוכנית Free). ב-Render בוחרים **New → Blueprint** ומחברים את ה-repo. בזמן היצירה Render יבקש להזין את `ADMIN_PASSWORD`.
