# איפה זה? 🌍

משחק טריוויה גיאוגרפי מרובה משתתפים בזמן אמת, בעברית. כל סיבוב מציג תמונה של עיר, מונומנט, אתר או מקום מפורסם, וכל שחקן בוחר מתוך ארבע אפשרויות איפה הוא נמצא. תשובה נכונה מזכה בנקודות, ותשובה מהירה מזכה ביותר.

**תשתית:** TypeScript · `client/server/shared` · Socket.IO (WebSocket) · React + Vite · Leaflet + OpenStreetMap · Docker · Render.

## איך משחקים

1. המארח נכנס ל"יצירת חדר חדש", ובוחר:
   - **קטגוריה:** ישראל, אירופה, אסיה, אמריקה, אפריקה ואוקיאניה, או מעורב (ברירת מחדל).
   - **דרגת קושי:** קל (ברירת מחדל), בינוני או מקצוענים. הדרגה משפיעה רק על בחירת המקומות, לא על הניקוד.
   - **מספר סיבובים:** 5, 10 (ברירת מחדל), 15 או 20. מקום לא חוזר פעמיים באותו משחק. אם אין מספיק מקומות בשילוב שנבחר, המשחק משתמש בכמה שיש ומציג הודעה.
   - **זמן לכל שאלה:** בין 3 ל-10 שניות (ברירת מחדל: 10).
2. השחקנים מצטרפים עם קוד החדר (או סריקת QR) ושם.
3. בכל סיבוב מוצגת תמונה בלי שם, ומתחתיה ארבעה כפתורים: התשובה הנכונה ושלושה מסיחים, בסדר אקראי. לחיצה על אפשרות בוחרת אותה ונועלת אותה מיד. יש טיימר לכל סיבוב.
4. אחרי כל סיבוב מוצגים התשובה הנכונה בירוק, הבחירות השגויות באדום, מי מהשחקנים בחר מה, שם המקום, העיר, המדינה ושורת מידע, ומפה קטנה עם המיקום האמיתי.
5. בסוף המשחק מוצגת טבלת הניצחון.

### האפשרויות
- הפורמט: "עיר, מדינה", או "אזור, מדינה" במקומות טבע (שדה `answerLabel` במאגר). בקטגוריית ישראל מוצג שם היישוב או האזור בלבד. כשמקום מישראל מופיע ב"מעורב", מתווסף לו ", ישראל".
- המסיחים נבנים אוטומטית מהמאגר (`buildRoundOptions` ב-`shared/src/content/places.ts`). מסיח אף פעם לא זהה לתשובה, כך שמקומות באותה עיר, כמו מגדל אייפל והלובר, לא משמשים מסיחים זה לזה. גם אין שתי אפשרויות זהות באותו סיבוב.
- **קל:** מסיחים מיבשות אחרות. בישראל: מקומות רחוקים.
- **בינוני:** תערובת של אחד-שניים מאותה יבשת, והשאר מיבשות אחרות.
- **מקצוענים:** מסיחים מאותה מדינה, ואחר כך מהקרובים ביותר באותה יבשת. בישראל: היישובים והאזורים הקרובים ביותר.
- הדרגה משפיעה רק על המקומות ועל המסיחים, לא על הניקוד.

### ניקוד
כמו ב"מי הזמר": תשובה שגויה או חסרה שווה 0. תשובה נכונה שווה בין 1000 (מיידית) ל-400 (ברגע האחרון), לפי המהירות. בשוויון מכריעים מספר התשובות הנכונות ואחריו הזמן הממוצע.

## מאגר המקומות

מקור האמת: [`data/places.json`](data/places.json). לכל מקום נשמרים שם, עיר, מדינה, טקסט התשובה (`answerLabel`), קטגוריה, דרגה, קואורדינטות (WGS84), קובץ תמונה ב-Wikimedia Commons, קרדיט (צלם + רישיון), ושורת מידע. פריטים שיש בהם ספק מסומנים בשדה `note`, כדי שאפשר יהיה לאמת אותם ידנית.

- **תמונות:** רק מ-Wikimedia Commons, ברישיון חופשי (Public domain, CC0, CC BY, CC BY-SA). הכתובת נבנית דרך `Special:FilePath` עם רוחב מתאים. מתחת לכל תמונה מוצג קרדיט עם קישור לדף הקובץ.
- **אימות מבני:** `npm run validate:places`
- **בדיקת תמונות:** `npm run check:images`. הסקריפט עובר על כל המאגר, מוודא שכל תמונה נטענת ושהרישיון שלה חופשי, ומדווח על קישורים שבורים. הבדיקה רצה אוטומטית ב-GitHub Actions בכל דחיפה (`.github/workflows/ci.yml`).
- **בניית מקומות מזרעים:** `node scripts/resolve-places.mjs`. הסקריפט מקבל רשימת זרעים (`scripts/seeds/*.json`), שולף קואורדינטות מ-Wikidata ומוויקיפדיה (ומסמן פער ביניהן), ובוחר תמונה ברישיון חופשי עם הקרדיט שלה.
- **גיליונות סקירה:** `python3 scripts/contact_sheets.py`. הסקריפט מכין לוחות של כל התמונות, כדי לוודא בעין שאין בהן שלט או כיתוב שחושף את התשובה.

## מסך ניהול — `/admin`

מוגן בסיסמה שמוגדרת במשתנה הסביבה `ADMIN_PASSWORD`. בלי הסיסמה המסך כבוי.

1. נכנסים עם הסיסמה. המאגר הנוכחי נטען לטיוטה בדפדפן (`localStorage`).
2. מוסיפים או עורכים מקום: שם, עיר, מדינה, טקסט התשובה (מוצע אוטומטית לפי העיר והמדינה, וניתן לעריכה), קטגוריה, דרגה, שם קובץ ב-Commons (או קישור לדף הקובץ), קרדיט ושורת מידע. אפשר לשלוף את הקרדיט אוטומטית מ-Commons.
3. **הקואורדינטות נבחרות בלחיצה על המפה בלבד**, בלי הקלדה. הן משמשות את מפת החשיפה. תצוגה מקדימה בודקת שהתמונה באמת נטענת, ומקום עם תמונה שבורה לא נשמר.
4. לוחצים **ייצוא**. יורד קובץ `places.json` מלא ומעודכן, ומחליפים בו את `data/places.json` ב-GitHub. Render יפרוס מחדש אוטומטית.

השרת לא כותב לדיסק, כי ב-Render Free ה-filesystem אינו קבוע. מקור האמת הוא תמיד הקובץ ב-repo.

## פריסה ב-Render

הקובץ `render.yaml` מגדיר שירות web יחיד (Docker, תוכנית Free). ב-Render בוחרים **New → Blueprint** ומחברים את ה-repo. בזמן היצירה Render יבקש להזין את `ADMIN_PASSWORD`.
